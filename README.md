# Vision training

## Task1 图像处理
- 均值滤波:
    - 核大小: 核大小越大, 边缘越模糊, 同时细节也更少, 使用9x9的核相较于5x5的边缘明显更不清晰
- 高斯滤波:
    - 核大小: 核大小越大, 边缘更加模糊, 细节更少, 在`sigma`均为1.5时, 9x9与3x3相比, 花瓣边缘明显模糊; 但是相较于均值滤波, 使用更大的核大小对边缘和细节的影响更小
    - 标准差: 标准差越大, 距离更远的像素影响越大; 均使用9x9的核大小时, `sigma`取25比`sigma`取1.5时花瓣边缘明显更加模糊, 细节更少
- 中值滤波:
    - 核大小: 核大小越大, 边缘更加平滑、明显, 细节更少, `ksize=9`时边缘比`ksize=3`时更加明显, 但是花瓣中间的细节明显减少

- 红色提取:
    - 阴影区域的H与花瓣中心区域的H相差不大, V值明显更低
    - 黄色区域的H与花瓣中心区域的H相差较大
    - 低区阈值设置为0,120,58到15,255,255包含部分与红色较为接近的橙色, 花瓣上端的黄色不算在内, 阴影包含在内
    - 高区阈值设置为170,120,58到179,255,255

- 形态学与轮廓
    - 选择了闭运算后的红色掩膜进行轮廓提取
